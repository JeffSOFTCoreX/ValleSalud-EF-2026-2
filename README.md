# Sistema ValleSalud

Proyecto del curso Lenguajes de Programación.

## Descripción
ValleSalud es un prototipo académico para la gestión básica de un centro de salud rural ficticio. 
El repositorio está organizado para integrar Programación Orientada a Objetos, programación funcional, 
persistencia, patrones de diseño, manejo de eventos y pruebas.

## Estructura
- `src/dominio/`: clases principales del sistema.
- `src/servicios/`: filtros, consultas, reportes y validaciones.
- `src/persistencia/`: conexión y acceso a datos.
- `src/patrones/`: implementación de patrones de diseño.
- `src/eventos/`: manejo de eventos o interfaz, si corresponde.
- `tests/`: pruebas automatizadas.
- `data/`: datos ficticios o base local de prueba.
- `docs/`: informe, UML, evidencias y declaración de IA.

## Ejecución
La forma definitiva de ejecución se completará cuando el equipo integre el código final.

## Datos
El proyecto debe trabajar únicamente con datos ficticios.
